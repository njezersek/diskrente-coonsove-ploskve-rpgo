# Diskretne Coonsove ploskve

### Seminar in predstavitev
- `seminar.pdf` vsebuje seminar o diskretnih Coonsovih ploskvah
- `predstavitev.pdf` vsebuje predstavitev seminarja


### Implementacija v Pythonu
Python implementacija se nahaja v datoteki `coons.py` v zvezku `coons.ipynb` pa najdete primere uporabe.

### Interaktivna implementacija
Interaktivna implementacija se nahaja v mapi `interactive-demo`. Za zagon potrebujete Node.js (`npm`):
```
cd interactive-demo
npm i
npm run dev
```
